# Table game-feel art — batch X5

Original artwork generated with the built-in image generation tool after inspecting the existing skills, skill-fx, stats, and landing art. No application code changed.

All exports use `cwebp -q 82`, preserve generated alpha, and have the exact dimensions below. Transparent assets were fitted inside 90% of the output canvas with centered clear padding. The backdrop fills its canvas and is fully opaque. Sizes are decimal KB (1 KB = 1,000 bytes); source PNGs remain outside the repository.

## Shared prompt

Use case: stylized-concept. Production jitu.fi game UI sprite matching the inspected skills, skill-fx and stats art: premium hand-painted toon/cel shading, chunky forms, heavy crisp ink #040B10 contour, polished bevels, ivory highlights from upper-left and navy #113048 shadows. Crest palette ivory #F2EDE1, gold #DAAE4B and bevel shadow #A17728, emerald #40D0A3. Monad purple #836EF9 at most a tiny accent. No text, letters, numbers, real logos, watermark, casino cues, card suits, dice, chips, religious symbols. Bold silhouette legible at small size.
